# 个人工作台

单用户个人工作台：错题学习（拍照录入 → OCR 识别 → 分类归档 → 随机抽题复习 → 六级掌握度评估 → PDF 导出试卷）+ 个人管理（仪表盘总览 / 待办 / 目标 / 收件箱 / 日历 / 复盘 / 热点资讯 / 收藏夹）。

## 版本

- 当前版本：**v1.15.0**
- 版本规则见 `AGENTS.md`：每次修改代码必须升级版本号并推送到 GitHub。

## v1.13.2 修复

- 目标与规划：状态分组（进行中 / 已完成 / 已搁置）、里程碑清单（勾选自动推进度）、挂关联待办（按完成率自动算进度）、目标日期倒数日。

## 运行（必须先启动本地服务）

```powershell
双击 start.bat      # 或手动：node server.js
```

然后浏览器打开 http://127.0.0.1:8788（start.bat 会自动打开）。关闭「本地服务」窗口即停止。数据保存在项目目录的 `mistake-book.db`。
