# 考研错题本（个人工作台）

单用户考研错题管理工具：拍照录入 → OCR 识别 → 人工校对 → 分类归档 → 随机抽题复习 → 六级掌握度评估 → 学习统计。

## 版本

- 当前版本：**v1.6.0**
- 版本规则见 `AGENTS.md`：每次修改代码必须升级版本号并推送到 GitHub。

## 当前能力（v1.6.0）

- 统一「识别录入」：单题（1 张图）与批量（多张图，题目/解题标记 + 配对）合为一个入口。
- 数据层：本地 SQLite（`server.js` 基于 Node 内置 `node:sqlite`，数据库文件 `mistake-book.db`），页面不再内置测试数据，种子数据在服务端首次启动时写入。
- 仪表盘一体化（已去重）：顶部核心指标（未掌握/总题数/错误轨道/累计时长）→ 今日推荐复习（含前 5 预览）→ 随机复习（抽题配置/做题/自评）→ 数据统计（四张图表，全站唯一图表区）。
- 去重审查：移除重复的指标卡、重复的「今日推荐」入口、重复的掌握度/薄弱知识点/学习时长图表。
- 复习自由选题：抽题后顶部题号导航，可「⏭ 跳过此题」、点任意题号切换、自评后自动跳下一道，小结单独统计跳过题。
- 设置简化：新增科目入口、按钮文案直白（＋加子科目/＋加章节/＋加知识点）、新增/重命名统一弹窗、加分支示例说明。
- OCR 服务：设置页可配置「模拟 / MinerU」，填 Token 后一键连通性测试（记录耗时）；MinerU 走 v4 上传→建任务→轮询→提取文本流程，数据仍存本机。
- 缺陷修复：真实 JSON 导入（合并/覆盖 + ID 重映射）、复习断点续传「继续上次」、学习时长按天落库（真实 30 天曲线）、题目编辑、知识点管理补全（增删改）、复习提醒、OCR 转手动输入。
- 本地持久化：数据存浏览器 localStorage，刷新不丢；首次进入自动播种演示数据。
- API 契约层：`api.js` 定义前后端唯一接口；后端接入只需切 `mode = "remote"`。
- 题库浏览 / 搜索筛选 / 知识点树 / 批量归类、随机复习 + 四档自评 + 六级掌握度、统计图表、JSON 导出导入、学习时长。

## 运行（必须先启动本地服务）

```powershell
双击 start.bat      # 或手动：node server.js
```

然后浏览器打开 http://127.0.0.1:8788（start.bat 会自动打开）。关闭「本地服务」窗口即停止。数据保存在项目目录的 `mistake-book.db`。

## 测试

```powershell
node smoke-test.mjs     # 功能链路：单题/批量录入、OCR、持久化
node layout-check.mjs   # 桌面/移动布局检查
node browser-shots.mjs chrome   # Chrome 截图 + 跨浏览器验证
node browser-shots.mjs edge     # Edge 截图 + 跨浏览器验证
```
