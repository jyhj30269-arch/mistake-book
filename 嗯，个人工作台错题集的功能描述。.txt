1. 错题录入
1.1 单题录入
支持拍照、相册选择、粘贴截图三种方式。
图片在前端压缩后上传至临时存储。
调用 OCR 识别，提供进度显示、取消机制、超时重试。
OCR 完成后进入人工校对界面：左图右文布局、公式渲染、低置信度区域高亮、支持源码/渲染视图切换。
保存前自动去重检测（同科目同类型下比对题面文本相似度）。
改进：去重增加时间窗口，7 天内同题面才提示疑似重复；超过 7 天视为新一轮复习遇到的老题，不拦截。
改进：疑似重复时弹窗提供"仍然录入"快捷按钮，不让用户感觉被阻断。
确认保存后立即删除临时图片。
改进：录入时不强制选择知识点分类，默认为"未分类"，降低录入门槛。
1.2 批量录入
支持批量上传题目图片与解题过程图片。
默认按文件名/拍摄时间自动配对。
改进：交互从"拖拽排序"改为"点选配对"（点击图 A → 点击图 B → 确认），适配移动端。
改进：自动配对不准时，提供"跳过配对，逐张录入"的降级路径。
批量提交 OCR，单题失败隔离，不影响其他题。
支持中途退出与断点续传。
改进：批量录入阶段不弹去重确认窗，改为录入完成后在列表页用角标/颜色提示"有 N 道疑似重复"，用户自行处理。
1.3 手动输入兜底
OCR 服务不可用或用户主动选择时，提供纯手动录入入口。
2. 题库浏览与管理
2.1 浏览模式
支持树形视图与列表视图切换。
改进：树形结构默认只展开到"科目 → 子科目"两级，章节和知识点用横向滑动标签页或折叠面板展示，避免手机端深层树形操作繁琐。
搜索/筛选作为主要浏览手段，树形结构作为辅助组织手段。
2.2 搜索与筛选
支持关键词、错因标签、日期范围搜索。
支持按六级掌握度、科目、错因、时间段及"未分类"进行多选筛选。
2.3 单题操作
查看详情、编辑、删除（需二次确认）、标记。
2.4 删除保护
禁止删除仍有题目引用的科目或子科目。
2.5 批量归类（新增）
改进：在"未分类"列表中支持多选 → 一次性指定知识点，弥补录入时不强制分类的设计。
3. 知识点管理
支持用户自行新增、修改、删除任意层级节点。
改进：科目/子科目必须支持完全自定义（数学一/二/三、英语一/二等），不能写死。
有子节点时禁止删除。
删除含题目的知识点时，相关题目自动归入"未分类"。
4. 错误归因体系
预设标签类别：知识点不会、粗心、计算错误、思路错误、时间心态、其他。
支持主因（唯一）+ 次因（多选）组合。
支持附加文字备注。
5. 随机抽题复习
5.1 抽题算法（重大改进）
采用 「分层优先 + 加权随机」 算法，解决纯随机导致的覆盖不均问题：
分层规则：按"被抽次数"将所有候选题目分为三层：
第 0 层：从未被抽到的题（绝对优先）。
第 1 层：被抽到过 1 次的题。
第 2 层：被抽到过 ≥2 次的题。
高层没抽完，绝不去低层抽。
层内加权：同一层内按掌握度赋予权重：
未复习 / 需要关注 / 重点攻克 / 顽固错题：权重 5
基本掌握：权重 3
比较掌握：权重 2
完全掌握：权重 1
做错加急：自评做错后标记 urgent_flag，下一次抽题时在当前层内权重 ×2，优先再次被抽到；下次抽到后清除标记。
覆盖保证：以 60 题、每次抽 3 题为例，20 次内 100% 全覆盖，不存在永远抽不到的题。
5.2 抽题配置
选择子科目、可选章节范围。
可选掌握度筛选（默认排除完全掌握）。
设置抽题数量。
5.3 做题流程
逐题展示（隐藏解析）→ 显示答案 → 自评 → 下一题。
5.4 自评维度（重大改进）
从原来的二选一改为 四档自评：
表格
选项	掌握度影响	说明
✅ 完全做对	正常升级	—
🟡 思路对，细节/计算错	升半级或不升	自动标记"计算薄弱"
🟠 有思路但做不完/卡住	不升级	自动标记"需巩固"
❌ 完全不会 / 蒙的	降级	重置轨道
5.5 实时反馈
自评后实时重算掌握度并更新标签动画（升级/重置提示）。
5.6 复习小结
展示做题统计、用时、掌握度变化及错题回顾列表。
5.7 状态保持
支持中途退出保存进度，下次可选择继续或重新开始。
5.8 死锁防护
选择特定筛选条件导致部分题目无法升级时，给予明确提示。
6. 六级动态掌握度模型（改进版）
6.1 自动计算
基于复习记录实时计算，不存储静态字段。
6.2 状态流转
包含七种状态：未复习、基本掌握、比较掌握、完全掌握、需要关注、重点攻克、顽固错题。
6.3 跨轨重置
做错立即跌落至"需要关注"，做对立即回升至"基本掌握"。
6.4 时间衰减（新增）
改进：引入遗忘衰减系数。超过 N 天未复习的题目，显示等级自动降一档（视觉上用虚线/半透明表示"衰减中"）。
在抽题算法中，"距上次复习时间"作为权重因子，越久没碰越优先被抽到。
在浏览列表中高亮"超过 X 天未碰"的题目。
7. 题目去重
保存前在同科目同类型下比对题面文本相似度。
改进：增加 7 天时间窗口，超期不提示。
改进：单题录入保留弹窗但提供"仍然录入"快捷按钮；批量录入改为事后列表角标提示。
8. 学习时长统计
8.1 智能计时（改进版）
进入复习/录入页面自动开始计时。
改进：失焦暂停阈值改为 30 秒以上；无操作暂停阈值改为 5~10 分钟。
改进：暂停后回来时显示"你离开了 X 分钟，是否计入学习时长？"由用户选择。
8.2 防丢失机制
定时暂存本地，异常退出后支持补录（仅限本设备或手动跨端补录）。
8.3 可视化
提供日/周/月时长柱状图及累计统计。
9. 复习提醒（改进版）
改进：利用 PWA Notification API + Service Worker 实现真正的后台定时推送（Android 支持良好，iOS 16.4+ 支持）。
改进：退而求其次的方案：接入邮件 / 日历（iCal/Google Calendar）作为外部提醒通道。
打开 App 时的检查保留，作为"二次确认"而非唯一提醒。
多端同步提醒状态（后期接云端后生效），避免多设备重复弹窗。

13. 新增功能
13.1 题目笔记/心得
每道题允许附加一段自己的文字笔记（如"这题的关键是换元"），比单纯看解析更有效。
13.2 错题关联
一道题支持关联多个知识点标签，不再限制单知识点归属。
13.3 标记/收藏
支持"星标""待二刷""经典好题"等自定义标记。
13.4 复习记录时间线
每道题展示完整复习历史（第几次、什么时候、对错、自评档位），方便回顾薄弱点变化。
13.5 今日推荐复习（新增核心入口）
首页最醒目位置放置"今日推荐复习"入口。
算法综合掌握度等级 + 距上次复习天数 + 错因权重，自动选出 10~20 道最该复习的题。
用户可手动调整数量。
引入简化版艾宾浩斯间隔重复作为调度层：
第 1 次做对 → 1 天后复习
第 2 次做对 → 3 天后
第 3 次做对 → 7 天后 → 14 天 → 30 天
做错 → 重置为 1 天
六级掌握度作为展示层，间隔重复作为调度层，两者并行。
